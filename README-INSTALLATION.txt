Adresse publique :

INSTALLER
1. Ouvrir le lien dans Safari sur l'iPhone.
2. Toucher le bouton Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Toucher « Ajouter ».

MISE À JOUR
Les modifications de la branche de développement ne sont pas visibles sur le site public avant leur fusion dans main. Après publication, fermer complètement l'application puis la rouvrir. Si l'ancienne version persiste, ouvrir le site dans Safari et le recharger ; le service worker installe la nouvelle version du cache.

DONNÉES
Binance Spot est la source principale ; Coinbase sert de secours pour les unités prises en charge. Le flux temps réel dépend de la disponibilité du WebSocket Binance. Les données de dérivés proviennent de Binance Futures. La source de liquidité macro nécessite un Worker Cloudflare facultatif configuré dans les réglages.

Si les sources de marché sont injoignables, l'application peut afficher une série de démonstration : le badge DÉMO · SIMULÉ doit alors être considéré comme un avertissement, jamais comme un prix réel.

Les signaux, scores et projections sont des outils d'analyse et ne garantissent aucun résultat. Les backtests ne reproduisent pas toutes les conditions réelles d'exécution.
